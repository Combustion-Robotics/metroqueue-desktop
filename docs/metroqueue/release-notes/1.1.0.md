MetroQueue Desktop 1.1.0

Play on desktop
- MetroQueue phones find this computer on your Wi-Fi, pair with a 6-digit code and control playback like a MetroQueue TV: queue, play next, radio, seek, volume, shuffle/repeat, handoff in both directions
- Settings → General → MetroQueue phones: allow connections, paired phones, Forget

Two-way sync with MetroQueue (Android 1.4.1+)
- Play history, custom transitions, custom vibes, local playlists and shared settings (Mix, gapless, lyrics, theme)

Mix
- Crossfade, Smart mix (tempo, beat and key analysis) and the Fade/Filter/Echo/Rise/Cut styles, plus your synced custom transitions
- Crossfades now take exactly as long as set (they used to run long)

Vibe mode
- The pixel-art scenes from the phone, identical, with your synced custom vibes, an editor and a full-screen player

Material 3 Expressive design
- New look throughout: colours from your seed colour or the artwork, Google Sans, M3 controls, navigation rail, player bar, dialogs and menus
- Appearance: Light/Dark/System, pure black, dynamic colour, seed colour (synced with the phone)

Notes
- macOS builds now need macOS 15 or newer
- Builds are unsigned for now, so the app can't update itself yet
